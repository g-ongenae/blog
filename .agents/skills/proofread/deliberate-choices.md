## Checks before "fixing" a verb

- « Je jouirais d’un bel autodafé » is *jouir*, not *jouer*. Work out which verb is meant before correcting a conjugation.

## Preferences

- In LinkedIn posts, restore the dropped « ne » (« Je n’ai jamais posté », « on n’utilisait »).
- Don't add redirect `aliases` when renaming a file unless the author says the page is already published.
