# 🕺 Dances

I've been interested in dancing for a long time.

When I was in high school, I watched "[Dance Street]"
(Seasons: [1&2][dance_street_s1_2], [3][dance_street_s3], [4][dance_street_s4])
dances battles on [France Ô].

When I was in university, I took a couples hours of courses to learn [Rock (4 times)].

I was often dancing when alone, or drunk.
People would tell me that I dance well then.
I did not believe them (and I was _right and wrong_).

At the end of 2022, my real journey started.
Since then, I've been dancing a lot and a lot.

I've danced (in the order of dates, not times spent):

- [Lindy Hop](./lindy-hop/README.md) (100+ hours)
- [Charleston](./charleston/README.md) (100+ hours)
- [Waltz](./waltz/README.md) (10+ hours)
- [West Coast Swing](./wcs/README.md) (50+ hours)
- [Solo Jazz](./jazz/README.md) (50+ hours)
- [Balboa](./balboa/README.md) (50+ hours)
- [Collegiate Shag](./shag/README.md) (10+ hours)
- [Blues](./blues/README.md) (50+ hours)

At first, I was only dancing as a leader.
In 2024, I started doing solo and following also.

At some point, I started taking notes after my classes and sharing them on my [Strava].
Even if no one (except my sister's lover) read them…
I've talked with a lot of people about dance.
Both those points made me want to write every down somewhere.
